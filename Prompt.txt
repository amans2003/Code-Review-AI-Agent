Users should be able to:

# Multi-Agent AI Review System

Create multiple AI agents:

1. Security Agent

* Detect secrets
* JWT vulnerabilities
* Mongo injection risks
* Unsafe eval usage
* Hardcoded credentials

2. Performance Agent

* Detect unnecessary re-renders
* Expensive loops
* Memory leaks
* Bad async handling

3. Clean Code Agent

* Naming issues
* Code duplication
* Readability problems
* Best practice violations

4. Architecture Agent

* Folder structure analysis
* Separation of concerns
* Component reusability
* API architecture review

5. Summary Agent

* Generate final overall review
* Create quality scores
* Summarize major issues

# Real-Time Streaming

Use Server Sent Events (SSE).

Frontend should receive live updates such as:

* Cloning repository...
* Scanning files...
* Running security analysis...
* Running performance checks...
* Generating final report...

Display streaming updates in real-time on UI.

---

# Redis Queue System

Use BullMQ with Redis.

Flow:

* User submits review request
* Backend pushes job into Redis queue
* Worker processes repository
* Worker sends streaming updates through SSE
* Final report saved into MongoDB
